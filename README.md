# WebGIS – Diagnóstico Geoecológico e Socioeconômico de Araguari (MG)

Visualizador da base cartográfica consolidada do projeto, desenvolvido pela Universidade Federal de Catalão (UFCAT) para a Prefeitura Municipal de Araguari. Site estático (Leaflet), gerado por `scripts/31_webgis.py` a partir do GeoPackage de entrega; fontes, métodos e limitações no Relatório Final do projeto.
